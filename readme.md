# Online Sales Analysis

## O projektu

Projekat predstavlja jednostavnu online prodavnicu napravljenu u Pythonu. Kroz projekat su primenjene osnove objektno orijentisanog programiranja.

## Mogućnosti programa

- Dodavanje novih proizvoda
- Prikaz proizvoda
- Izmena podataka o proizvodima
- Uklanjanje proizvoda
- Dodavanje proizvoda u korpu
- Prikaz sadržaja korpe
- Izračunavanje ukupne vrednosti korpe

## Struktura projekta

- `main.py` – pokretanje programa
- `product.py` – klasa za proizvode
- `product_manager.py` – upravljanje proizvodima
- `cart.py` – rad sa korpom
- `.gitignore` – datoteke koje se ne prate u Git-u

## Pokretanje programa

Program se pokreće iz terminala komandom:

```bash
python main.py
```
